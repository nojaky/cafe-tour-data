개인정보처리방침

카페 탐방록은 사용자의 개인정보 보호를 중요하게 생각합니다.

본 개인정보처리방침은 카페 탐방록 앱에서 처리되는 정보와 그 이용 목적, 보관 및 삭제 방법을 안내합니다.

1. 수집하는 개인정보

카페 탐방록은 별도의 회원가입을 요구하지 않으며, 이름, 전화번호, 이메일 주소 등의 개인정보를 직접 수집하지 않습니다.

앱은 사용자의 현재 위치 정보를 수집하지 않습니다. 다만 사용자가 직접 입력한 카페 주소는 카페 기록 관리, 지도 앱 연결, 탐방 캘린더 표시 및 통계 제공을 위해 사용자의 기기 내부에 저장될 수 있습니다.

2. 앱에서 저장되는 정보

사용자가 앱에 입력하거나 선택한 다음 정보는 사용자의 기기 내부에 저장됩니다.

  • 카페명
  • 주소
  • 방문 기록 또는 메모
  • 별점
  • 방문일
  • 즐겨찾기 여부
  • 사용자가 선택한 카페 사진 및 메뉴 사진

3. 탐방 캘린더 및 통계 정보

앱은 사용자가 저장한 방문일을 기준으로 탐방 캘린더를 표시할 수 있습니다.

또한 사용자가 저장한 기록을 바탕으로 월별 방문 개수, 지역별 방문 통계, 지역별 평균 별점, 전체 방문 카페 수, 평균 별점, 저장된 사진 수 등의 통계 정보를 앱 내부에서 계산하여 표시할 수 있습니다.

해당 캘린더 및 통계 정보는 사용자의 기록을 보기 쉽게 제공하기 위한 목적으로만 사용되며, 개발자의 별도 서버로 전송되지 않습니다.

4. 사진 접근 권한

앱은 사용자가 카페 사진 또는 메뉴 사진을 등록할 수 있도록 기기의 사진 선택 기능을 사용할 수 있습니다.

앱은 사용자가 직접 선택한 사진만 앱 내부 저장소에 복사하여 저장하며, 사용자가 선택하지 않은 사진에는 접근하지 않습니다.

앱은 사용자가 선택한 사진을 외부 서버로 전송하지 않습니다.

5. 백업 및 복원

앱은 사용자가 직접 백업 기능을 실행하는 경우, 저장된 카페 기록과 사진을 ZIP 파일 형태로 내보낼 수 있습니다.

백업 파일은 사용자가 직접 선택한 위치에 저장되며, 개발자의 별도 서버로 전송되지 않습니다.

앱은 사용자가 직접 복원 기능을 실행하는 경우, 사용자가 선택한 백업 파일에서 카페 기록과 사진을 앱 내부 저장소로 복원할 수 있습니다.

백업 파일은 사용자가 직접 관리하며, 사용자가 별도로 생성한 백업 파일은 앱에서 자동으로 삭제하지 않습니다.

6. 추천 카페 정보

앱은 추천 카페 정보를 제공하기 위해 외부에 공개된 추천 카페 데이터 파일을 불러올 수 있습니다.

추천 카페 정보는 앱 화면에 표시하기 위한 목적으로만 사용되며, 사용자의 카페 기록, 사진, 메모, 별점 등의 개인 기록 정보는 추천 카페 정보 제공을 위해 외부로 전송되지 않습니다.

추천 카페 정보 업데이트 시 인터넷 연결이 필요할 수 있습니다.

7. 개인정보의 제3자 제공

카페 탐방록은 사용자의 카페 기록, 사진, 메모, 별점, 방문일 등의 정보를 개발자의 별도 서버에 전송하거나 제3자에게 제공하지 않습니다.

단, 사용자가 앱 내 버튼을 눌러 외부 서비스로 이동하는 경우, 해당 외부 서비스 이용 과정에서의 정보 처리는 해당 서비스의 개인정보처리방침이 적용됩니다.

8. 외부 서비스 연결

앱 내의 지도 버튼, 네이버 톡톡 문의 버튼, 추천 카페 관련 외부 링크 등을 누르면 외부 서비스로 이동할 수 있습니다.

  • 네이버 지도
  • 구글 지도
  • 네이버 톡톡
  • 외부 웹페이지 또는 브라우저
  • 추천 카페 정보를 불러오기 위한 외부 공개 데이터 주소

지도 기능은 사용자가 입력한 카페 주소를 지도 앱 또는 웹 지도에서 확인하기 위해 사용됩니다.

외부 서비스 이용 시 해당 서비스의 개인정보처리방침이 적용됩니다.

9. 데이터 보관 및 삭제

사용자가 저장한 카페 기록과 사진은 앱을 삭제하거나 앱 내에서 해당 기록을 삭제할 때까지 사용자의 기기 내부에 보관됩니다.

사용자는 앱 내에서 저장된 카페 기록을 삭제할 수 있습니다.

앱 내에서 카페 기록을 삭제하면 앱 화면 및 앱 데이터베이스에서 해당 기록이 삭제됩니다.

앱을 삭제하면 기기에 저장된 앱 데이터도 함께 삭제될 수 있습니다.

단, 사용자가 별도로 생성한 백업 파일은 앱 삭제 또는 기록 삭제와 별개로 사용자가 직접 삭제해야 합니다.

10. 보안

앱은 사용자의 정보를 개발자의 별도 서버에 저장하지 않으며, 기록 데이터는 사용자의 기기 내부에 저장됩니다.

사용자의 카페 기록과 사진은 기기 내부 저장소 및 앱 데이터베이스에 저장되며, 사용자의 기기 보안 상태에 영향을 받을 수 있습니다.

11. 아동 개인정보

카페 탐방록은 아동을 대상으로 한 앱이 아니며, 아동의 개인정보를 고의로 수집하지 않습니다.

12. 개인정보처리방침 변경

본 개인정보처리방침은 앱 기능 변경, 서비스 운영 방식 변경 또는 관련 법령 및 정책 변경에 따라 수정될 수 있습니다.

개인정보처리방침이 변경되는 경우, 앱 또는 앱 배포 페이지 등을 통해 변경 내용을 안내할 수 있습니다.
